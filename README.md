# Deep Learning for Computer Vision and NLP

Практичні ноутбуки до курсу магістратури «Deep Learning for Computer Vision and NLP». Кожен ноутбук відповідає
темі конспекту й містить увесь код заняття: завантаження даних, підготовку, навчання та оцінювання моделей.
Теоретичний матеріал і пояснення до коду — у конспектах на навчальній платформі курсу.

Ноутбуки збережено разом із результатами виконання (виводами клітинок і графіками), тому їх можна переглядати
прямо на GitHub без запуску.

## Як запустити

### Google Colab

1. Відкрийте ноутбук за посиланням **Colab** у таблиці або кнопкою *Open in Colab* на початку ноутбука.
2. Для ноутбуків з позначкою **GPU** увімкніть прискорювач: *Runtime → Change runtime type → T4 GPU*.
3. Виконайте клітинки по черзі або всі одразу (*Runtime → Run all*).

Дані й попередньо навчені моделі ноутбуки завантажують самі. Пакети, яких немає в Colab (`gensim`,
`ultralytics`, `optuna`, `evaluate`, `rouge_score`), встановлюються першими клітинками відповідних ноутбуків.

### Kaggle

Ноутбуки із суфіксом `_kaggle` розраховані на тривале навчання, тому їх зручно запускати на Kaggle.

1. Відкрийте ноутбук за посиланням **Kaggle** у таблиці або кнопкою *Open in Kaggle*.
2. У налаштуваннях ноутбука оберіть *Accelerator → GPU T4 x2* і залиште *Internet* увімкненим.
3. Натисніть *Save Version → Save & Run All*: ноутбук виконається у фоновому режимі (до 12 годин), а результати
   збережуться у версії ноутбука.

GPU P100 поточна збірка PyTorch не підтримує (CUDA 13 потребує GPU з compute capability 7.5 і вище), тому
обирайте T4.

### Локально

Знадобляться Python 3.13 і Jupyter; для ноутбуків з позначкою GPU — відеокарта NVIDIA з підтримкою CUDA.

```bash
git clone https://github.com/BetterED-Neoversity/DEEP-LEARNING-FOR-COMPUTER-VISION-AND-NLP.git
cd DEEP-LEARNING-FOR-COMPUTER-VISION-AND-NLP

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install jupyter ipywidgets numpy pandas matplotlib seaborn scikit-learn tqdm \
    torch torchvision transformers datasets evaluate rouge_score \
    nltk spacy gensim ultralytics optuna kagglehub gdown

jupyter notebook notebooks/
```

Версію PyTorch з підтримкою GPU встановлюйте за інструкцією на [pytorch.org](https://pytorch.org/get-started/locally/).
Ноутбуки складають завантажені дані в теку `data/` поруч із собою (у Colab — `/content/data`), вектори
Теми 10 — у `pretrained_models/`, а моделі й датасети Hugging Face — у стандартний кеш `~/.cache/huggingface`.

## Корисно знати

- **Результати трохи відрізняються від запуску до запуску**: ваги ініціалізуються випадково, дані
  перемішуються, тож числа у вашому прогоні можуть дещо відрізнятися від збережених у ноутбуках і наведених у
  конспектах.
- **`Module_2_Lecture_3_Class`**: кілька клітинок навмисно завершуються помилкою — вони показують, коли
  broadcasting і `torch.stack` не працюють. *Run all* зупиниться на першій такій клітинці; далі виконуйте
  клітинки окремо або командою *Runtime → Run after*.
- **`Module_5_Lecture_10_Class`**: вектори Google News займають ≈3,6 ГБ на диску й кілька гігабайтів оперативної
  пам'яті. У ноутбуці позначено місце, де варто перезапустити ядро, якщо пам'яті не вистачає.
- **Попередження про `HF_TOKEN`** у ноутбуках, що працюють з Hugging Face Hub, можна ігнорувати: моделі й датасети
  завантажуються й без токена, а токен лише пришвидшує завантаження.
- **Метрики класифікації текстів** (Теми 9–10): ROC-AUC рахується за ймовірностями позитивного класу
  (`predict_proba`), а не за передбаченими класами.
